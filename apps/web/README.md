# Web

## Dependencies

- axios
  - `fetch` adapter: `pnpm add @haverstack/axios-fetch-adapter`
- lodash-es
- localforage
- React Router
  - Installation: `pnpm add react-router`
  - File-convention based routes: `pnpm add @react-router/fs-routes`
    - Doc <https://reactrouter.com/how-to/file-route-conventions>
- TailwindCSS
  - Installation: <https://tailwindcss.com/docs/installation/using-vite>
- HeroUI 3.x.x
  - Installation: <https://heroui.com/en/docs/react/getting-started/quick-start>
  - Install skills: `pnpx skills add heroui-inc/heroui`
